# L’Onglerie — сайт-витрина

Одностраничный сайт на HTML, CSS и JavaScript без сборки и зависимостей.

## Запуск локально

Видео в первом экране скачивается целиком через `fetch`, поэтому страницу нужно открывать через локальный сервер, а не двойным щелчком по файлу:

```bash
python -m http.server 8080
```

Затем откройте http://localhost:8080.

## Публикация на GitHub Pages

1. Загрузите содержимое архива в корень репозитория.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.

## Структура

| Файл | Что это |
|---|---|
| `index.html` | Разметка страницы |
| `styles.css` | Стили (шрифт Inter подключается с Google Fonts) |
| `main.js` | Скролл-видео, каталог и корзина, анимации |
| `hero-1080.mp4`, `hero-720.mp4` | Видео первого экрана: для компьютеров и для телефонов, каждый кадр ключевой |
| `img/products/` | Фото товаров, 900×900, белый фон |
| `img/frame-*.jpg` | Кадры из видео для блоков «Ритуал», «Состав» и галереи |

Товары, цены и ссылки на фото — массив `PRODUCTS` в `main.js`.

## Демо-режим

Цены взяты из брифа и требуют подтверждения. Отзывы, цифры статистики, состав и порог бесплатной доставки — заглушки. Оформление заказа и подписка ничего не отправляют.
